# Trading Dashboard - Developer Documentation

## Overview

This project is a **Stock Screening Platform** for NSE (National Stock Exchange) and BSE (Bombay Stock Exchange) that identifies stocks showing progressive momentum using the **12-Condition Progressive Spike Strategy**.

---

## Navigation Pages (dashboard_full.py)

### 1. Dashboard (Home Page)
- **Purpose**: Main landing page showing stock screening summary
- **Features**:
  - Displays total stock count, NSE/BSE breakdown
  - Shows stocks passing all **12 Progressive Spike conditions**
  - "Add to Watchlist" button for each signal
  - Uses `ProgressiveSpiker.get_signals()` to find signals

---

### 2. Data Health
- **Purpose**: Inspect and download raw data files
- **5 Tabs**:

| Tab | File | What it Shows |
|-----|------|---------------|
| Download | - | Button to manually trigger data update |
| Primary File | `dashboard_cloud.csv` | Combined processed data with all averages |
| NSE Bhav | `raw/nse_bhav_*.csv` | Raw NSE bhavcopy (price data) |
| NSE Delivery | `raw/nse_delivery_*.csv` | Raw NSE delivery data |
| BSE Data | `raw/bse_bhav_*.csv` | Raw BSE bhavcopy |

---

### 3. Signals
- **Purpose**: Show today's signals with momentum scoring
- **Location**: Lines 250-350 in `dashboard_full.py`
- **Features**:
  - Calculates **Momentum Score** (0-100):
    ```
    Score = Delivery_Momentum (33) + Turnover_Momentum (33) + ATW_Momentum (34)
    ```
  - Auto-logs signals to `data/signal_history.csv`
  - Shows Signal History with stats (total logged, unique stocks, date range)
  - Download button for full CSV export

---

### 4. Verify Conditions
- **Purpose**: Debug/verify each stock passes all 12 conditions
- **Location**: Lines 352-394 in `dashboard_full.py`
- **Shows for each signal**:
  ```
  Baseline (3 Conditions):
  1. Delivery % ≥ 50
  2. Turnover ≥ ₹50L
  3. ATW ≥ ₹20K
  
  Progression (9 Conditions):
  4-6.  Today Delivery > 1W > 1M > 3M
  7-9.  Today Turnover > 1W > 1M > 3M
  10-12. Today ATW > 1W > 1M > 3M
  ```
- Uses ✅/❌ to visually show pass/fail for each condition

---

### 5. Watchlist
- **Purpose**: Track active positions with entry/exit management
- **Location**: Lines 396-491 in `dashboard_full.py`
- **Features**:
  - Auto-updates current prices from `dashboard_cloud.csv`
  - **Close & Record**: Logs the trade to history for win rate tracking
  - **Remove Only**: Deletes without recording (e.g., cancelled entries)
  - Shows **Quick Stats**: Active positions, approximate value, unrealized P&L
  - Download watchlist as CSV
- Uses `WatchlistManager` class for persistence

---

### 6. Win Rate
- **Purpose**: Performance analytics for closed trades
- **Location**: Lines 493-512 in `dashboard_full.py`
- **Metrics Shown**:

| Metric | Description |
|--------|-------------|
| Total | Total closed trades |
| Winners | Trades with positive return |
| Win Rate % | Winners ÷ Total × 100 |
| Avg Return % | Average percentage return across all trades |

- Data comes from `WatchlistManager.get_win_rate()`

## Data Flow

```
auto_update_smart.py → data/dashboard_cloud.csv → dashboard_full.py
                                                        ↓
                                              ProgressiveSpiker
                                                        ↓
                                    Signals → Watchlist → Win Rate
```

The dashboard reads from `dashboard_cloud.csv` which is generated by the daily update pipeline. All pages use this single source of truth.

## Progressive Spike Strategy - 12 Conditions

### Baseline Conditions (Must Pass)
1. **Delivery % ≥ 50%** - High delivery indicates institutional buying
2. **Delivery Turnover ≥ ₹50 Lakhs** - Minimum liquidity threshold
3. **ATW (Average Trade Worth) ≥ ₹20,000** - Filters penny stocks

### Progressive Conditions (Momentum Confirmation)
| # | Metric | Condition |
|---|--------|-----------|
| 4 | Delivery % | Today > 1-Week Avg |
| 5 | Delivery % | 1-Week Avg > 1-Month Avg |
| 6 | Delivery % | 1-Month Avg > 3-Month Avg |
| 7 | Delivery Turnover | Today > 1-Week Avg |
| 8 | Delivery Turnover | 1-Week Avg > 1-Month Avg |
| 9 | Delivery Turnover | 1-Month Avg > 3-Month Avg |
| 10 | ATW | Today > 1-Week Avg |
| 11 | ATW | 1-Week Avg > 1-Month Avg |
| 12 | ATW | 1-Month Avg > 3-Month Avg |

## Screening Modes

The `ProgressiveSpiker` class supports 3 modes:

```python
from progressive_screener import ProgressiveSpiker

screener = ProgressiveSpiker(df)

# 1. Relaxed Mode (6 conditions: Today > 1W > 1M)
# Best when you have < 66 days of data
signals = screener.get_signals(strict_mode=False)

# 2. Baseline Only (3 conditions)
# Shows all stocks meeting minimum thresholds
baseline = screener.get_baseline_signals()

# 3. Strict Mode (All 12 conditions)
# Requires 66+ days of historical data
strict = screener.get_signals(strict_mode=True)
```

**Note**: With limited historical data (< 66 days), 1M and 3M averages will be identical, causing strict mode to return 0 results. Use relaxed mode in this case.
